## 详细 User Journey

### UJ-SEC-01｜容器分享时的安全检查

**场景** 用户准备将 `.elf` 文件发送给他人或上传到共享位置，系统在分享前执行安全扫描。

**场景流程**

- 用户通过"导出"或"分享"功能准备传输 `.elf` 文件。

- 系统在导出前执行安全扫描：
    - 扫描所有 Block 内容中是否存在疑似敏感信息（与 UJ-SEC-03 相同的检测规则）。
    - 扫描 Block 目录下的文件（如 `src/` 目录中的配置文件）是否包含凭据。
    - 检查 Event Log 的历史事件中是否存在已被删除但仍在历史中的敏感信息。

- 如果检测到安全风险，系统展示扫描报告：
    - 列出疑似敏感信息的位置和内容预览。
    - 建议操作："清理后再分享" 或 "确认安全后继续"。

- 用户确认后方可继续导出。

**预期结果**

- **出口安全门：** 即使过程中疏忽了（如 UJ-SEC-03 被用户强制跳过），分享前的安全扫描提供了最后的检查机会。

- 历史事件中的敏感信息是一个容易被忽视的风险——用户可能在 Block 中写入了密码后又删除了，但 Event Log 中仍保留着历史记录。安全扫描覆盖了这一盲区。
