## 详细 User Journey

### UJ-MATCH-01｜新 Task 触发相似度检索

**场景** 用户或 AI Agent 创建了一个新 Task，系统自动在后台启动历史经验检索。

**场景流程**

- 用户创建新 Task 并填写任务描述（意图描述）。

- 系统从 Task 描述中提取语义特征：关键词、涉及的技术领域、任务类型（新功能/修复/重构等）。

- 系统在当前 `.elf` 容器的 Archive 库中发起相似度检索。

- 检索在后台异步进行，不阻塞 Task 创建流程。

**预期结果**

- **零延迟启动：** Task 创建立即完成，Pattern Matcher 在后台运行，用户无需等待检索结果。

- 即使 Archive 库为空（项目早期），系统也正常工作——只是不会返回匹配结果，Task 照常执行。
