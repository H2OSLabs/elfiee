## 详细 User Journey

### UJ-ASSET-01｜导入资产文件到 Block

**场景**
用户需要在文档中使用一张截图、一份数据文件或其他二进制资源。用户将外部文件导入到某个 Block 的资产目录中，使其成为 `.elf` 容器的一部分。

**流程**

- 用户选择目标 Block，触发"导入资产"操作（拖拽文件到 Block 区域，或通过菜单选择文件）。
- 系统将文件复制到该 Block 对应的 `block-{uuid}/` 目录中。
- 系统记录一条资产导入 Event，包含文件名、文件类型与文件哈希。
- 导入完成后，该文件在 Block 的资产列表中可见。

**预期结果**

- **容器内化**：外部文件被复制进 `.elf` 容器，不再依赖原始路径。
- **归属明确**：资产文件明确归属于目标 Block，存储在其专属目录中。
- **可追溯**：导入行为被记录为 Event，可在 Timeline 中追溯何时、由谁导入了哪个文件。
