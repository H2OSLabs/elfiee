## 详细 User Journey

### UJ-PERF-01｜大项目首次加载

**场景** 用户打开一个包含数百个 Block、数万条 Event 的大型 `.elf` 项目，期望在合理时间内进入可编辑状态。

**场景流程**

- 用户双击 `.elf` 文件或从 Dashboard 打开项目。

- 系统开始加载 `.elf` 容器（ZIP 解压 + SQLite 连接），UI 立即展示加载指示器（进度条或骨架屏）。

- 系统优先加载项目元数据和顶层 Block 结构（目录树），让用户先看到项目的整体轮廓。

- 后台继续加载深层 Block 内容和关联数据，每完成一个 Block 的投影就推送到前端渲染。

- 当核心 Block（如用户上次编辑的 Block）完成加载后，系统标记为"可交互状态"，用户可以开始编辑。

**预期结果**

- **感知速度优先：** 用户不需要等待所有 Block 加载完毕才能开始工作。"可交互时间"远早于"完全加载时间"。

- 加载过程中 UI 始终有反馈（进度指示器、逐步出现的内容），不会出现"应用无响应"的感知。
